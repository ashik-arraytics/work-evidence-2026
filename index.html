Median downloads per day in each month, Nov 2025 to Oct 2026. The shaded part is the review period. Each chart has its own scale.

WordPress.org counts updates as downloads too, so a month with more releases also lifts this number. Read it as "how active the plugin is", not as new customers. Using the median day keeps one big release day from skewing a month.
